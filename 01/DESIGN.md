# 界面设计说明

此文档是对现有界面风格的整理，不代表全部功能已在展示版接通。业务和模型条件见 README。

## 使用场景

- 店员在电脑或平板上接待客户、采集需求并展示候选商品。
- 门店语音页通过语音、卡片和照片组织接待过程。
- 客户通过简洁的方案页面查看搭配建议。
- 管理员集中处理商品、员工及咨询记录。

## 视觉风格

暖奶油底色与深酒红文字，搭配大幅空间照片，强调软装门店的材料感。界面区分顾问操作区、管理区和客户方案页，避免所有内容堆成相同卡片。

| 用途 | 颜色 |
|---|---|
| 页面背景 | #F5F1E8 |
| 内容表面 | #FCFAF5 |
| 次级表面 | #E7E0D3 |
| 文字与主操作 | #4A1712 |

## 交互原则

1. 咨询按照片、分析、偏好、推荐、预览分步进行。
2. 语音与屏幕卡片使用同一商品事实，交互事件反馈给会话。
3. 上传、保存、模型分析分别呈现状态，失败时明确提示。
4. 资料不足时保留空值，不用演示效果冒充真实推荐。
5. 页面考虑手机和平板操作、键盘焦点以及减少动画偏好。
